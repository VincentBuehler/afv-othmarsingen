FC Othmarsingen – Daten-API

Statischer Datenstand für die inoffizielle FC-Othmarsingen-App. Die Dateien werden von python -m tools.export_static erzeugt und hier unverändert ausgeliefert – kein Server, keine Datenbank im Betrieb.

Einstiegspunkte: meta.json · club.json · stats/overview.json · matches/upcoming.json

Datenquelle: Matchcenter des Aargauer Fussballverbands (matchcenter.afv.ch). Inoffizielles Projekt, keine Gewähr für Richtigkeit. Quellcode: github.com/VincentBuehler/afv-othmarsingen
